# Machine-Learning–Guided Inverse Design of Porous Silicon Metamaterials

This repository contains the dataset, machine-learning code, and molecular dynamics input files associated with the published research article:

> **Machine-Learning–Guided Inverse Design of Porous Silicon Metamaterials for Targeted Thermal Conductivity**  
> Othman Soubai, Younes Abouelhanoune  
> LSA Laboratory, ENSAH, Abdelmalek Essaadi University, Al-Hoceima, Morocco  
> *Computational Materials Science*, Volume 275, Article 115060 (2026)  
> https://doi.org/10.1016/j.commatsci.2026.115060

## Overview

A machine-learning–guided inverse design framework for porous silicon thermal metamaterials. A dataset of 18 nanoporous silicon geometries was generated using non-equilibrium molecular dynamics (NEMD) with the Müller-Plathe method, spanning porosities from 0% to 36.8% and thermal conductivities from 1.28 to 12.03 W/(m·K). Every geometric descriptor has been verified against the simulation log that produced it. Random Forest and Gaussian Process surrogate models map pore-wall geometry to lattice thermal conductivity, and the Gaussian Process model drives uncertainty-aware inverse design. Three ML-designed geometries, selected by a constrained search over the buildable grid that excludes previously sampled configurations, were validated by independent NEMD; all three agree with prediction within one combined standard deviation.

## Repository structure

- `data/`    : ML training dataset, model outputs, inverse-design candidates, grid predictions, and per-seed conductivities
- `lammps/`  : LAMMPS NEMD input scripts, Stillinger-Weber potential, SLURM template, and job specifications
- `ml/`      : training, inverse design, kappa extraction, and reviewer-response analysis scripts
- `figures/` : figure-generation scripts

The dataset used for training is defined in the `DATA` block of `ml/ml_train_paper2.py`; the figure scripts read from it directly, so figures and tables cannot drift apart.

Note: the six-panel ML results figure is generated by `ml/ml_train_paper2.py`, not by a separate script in `figures/`.

## Requirements

Python 3.11+, LAMMPS (2 Aug 2023, Update 2 or later) with the MANYBODY package.
Install Python dependencies:

    pip install -r requirements.txt

## Reproducing the results

1. Run NEMD (optional — all conductivities are provided): submit `lammps/submit_template.slurm` with the desired pore geometry via `-var` flags. Job specifications for the validation and convergence runs are in `lammps/jobs_*.csv`.
2. Extract thermal conductivity from the NEMD output: `python ml/analyze_kappa.py`
3. Train the surrogates and generate the ML results figure: `python ml/ml_train_paper2.py`
4. Run the constrained inverse design over the buildable grid: `python ml/inverse_grid.py`
5. Reproduce the separated cross-validation metrics and the collinearity analysis: `python ml/reviewer_analysis.py`
6. Extract conductivities for the validation and convergence runs: `python ml/extract_new.py`

## NEMD methodology

- Müller-Plathe reverse NEMD (`fix thermal/conductivity`), Stillinger-Weber potential.
- Production system: 8 × 8 × 48 unit cells (24,576 atoms in the bulk reference). Finite-size convergence runs additionally use N_z = 72 and 96 via `lammps/in.nemd_size`.
- Timestep 1 fs; periodic boundary conditions in x, y, z.
- 50 ps NVT equilibration at 300 K, then 500 ps NEMD production.
- kappa = Q / (2 A |dT/dz|), with A the full geometric cross-section.
- Three independent seeds per geometry; mean ± standard deviation reported. Six seeds were used for the highest-conductivity validation candidate, where the seed-to-seed scatter is largest. All individual seed values are given in `data/kappa_per_seed_revision.csv`.
- Porosities are atom-counted as (N_bulk − N_remaining)/N_bulk rather than taken from the nominal design.
