# Machine-Learning–Guided Inverse Design of Porous Silicon Metamaterials

This repository contains the dataset, machine-learning code, and molecular dynamics input files for the study:

> **Machine-Learning–Guided Inverse Design of Porous Silicon Metamaterials for Targeted Thermal Conductivity**
> O. Soubai, Y. Abouelhanoune
> LSA Laboratory, ENSAH, Abdelmalek Essaadi University, Al-Hoceima, Morocco
> *Submitted to Computational Materials Science (2026)*

## Overview

A machine-learning–guided inverse design framework for porous silicon thermal metamaterials. A dataset of 19 nanoporous silicon geometries was generated using non-equilibrium molecular dynamics (NEMD) with the Müller-Plathe method, spanning porosities from 0% to 37% and thermal conductivities from 1.28 to 12.03 W/(m·K). Random Forest and Gaussian Process surrogate models map pore-wall geometry to lattice thermal conductivity, and the Gaussian Process model drives uncertainty-aware inverse design. One novel ML-designed geometry was validated by independent NEMD (κ = 1.39 ± 0.01 vs. 1.52 ± 0.20 predicted), and a second candidate provided a reproducibility cross-check.

## Repository structure

- data/    : NEMD dataset (19 geometries) and ML output CSVs
- lammps/  : LAMMPS NEMD input script, Stillinger-Weber potential, SLURM template
- ml/      : ML training (RF + GP, inverse design) and kappa-extraction scripts
- figures/ : figure-generation scripts

Note: Figure 3 (ML results) is generated by ml/ml_train_paper2.py, not a separate figures/ script.

## Requirements

Python 3.11+, LAMMPS (2 Aug 2023, Update 2 or later) with MANYBODY package.
Install Python dependencies:

    pip install -r requirements.txt

## Reproducing the results

1. Run NEMD (optional — dataset provided): submit lammps/submit_template.slurm with the desired pore geometry via -var flags.
2. Extract thermal conductivity: python ml/analyze_kappa.py
3. Train ML models, run inverse design, and generate the ML results figure: python ml/ml_train_paper2.py

## NEMD methodology

- Müller-Plathe reverse NEMD (fix thermal/conductivity), Stillinger-Weber potential.
- System: 8 x 8 x 48 unit cells (24,576 atoms in bulk reference).
- Timestep 1 fs; periodic boundary conditions in x, y, z.
- 50 ps NVT equilibration at 300 K, then 500 ps NEMD production.
- 20 temperature bins along z; kappa = Q / (2 A |dT/dz|), A = full geometric cross-section.
- 3 independent seeds per geometry; mean ± standard deviation reported.
